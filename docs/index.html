Paper rejim
Soxta pul bilan sinov. Bot haqiqiy narxlarni kuzatadi, lekin hech qanday haqiqiy pul sarflanmaydi.
Token / memecoin
Kripto “tanga”. Yangi memecoinlarning ko‘pi tez qadrsizlanadi yoki firibgarlik bo‘lib chiqadi.
Honeypot
Sotib olsa bo‘ladi, lekin qayta sotib bo‘lmaydigan tuzoq token.
Rug pull
Token yaratuvchilari pulni olib qochishi.
Likvidlik qulflangan (LP locked)
Savdo puli yaratuvchi tomonidan olib qo‘yilmasligi uchun qulflangan. Qulflangani xavfsizroq.
Slippage (narx farqi)
Kutilgan narx bilan haqiqiy bitim narxi orasidagi farq. Katta bo‘lsa, bot kirmaydi.
Stop-loss / Take-profit
Zarar belgilangan darajaga yetsa yoki foyda maqsadga yetsa, bot avtomatik chiqadi.
